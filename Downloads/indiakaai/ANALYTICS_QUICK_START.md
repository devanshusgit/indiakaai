## 🚀 3-Step Setup (10 Minutes)

### **Step 1: Verify Analytics (2 min)**
1. Go to https://analytics.google.com
2. Check if you see "IndiaKaAI" property
3. Click **Realtime** → Visit your site
4. See yourself in real-time report ✅

### **Step 2: Verify Search Console (5 min)**
1. Go to https://search.google.com/search-console
2. Add property: `https://indiakaai.com`
3. Choose **HTML tag** verification
4. Copy verification code
5. Replace `YOUR_VERIFICATION_CODE` in `index.html` line 20
6. Deploy: `vercel --prod`
7. Click **Verify** ✅

### **Step 3: Submit Sitemap (1 min)**
1. In Search Console → **Sitemaps**
2. Enter: `sitemap.xml`
3. Click **Submit** ✅
