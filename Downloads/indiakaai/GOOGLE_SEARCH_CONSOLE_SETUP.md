## ⚠️ Common Issues & Solutions

### Issue 1: Sitemap Not Found
**Solution:** 
- Verify sitemap is accessible: https://indiakaai.com/sitemap.xml
- Check for XML syntax errors
- Resubmit sitemap

### Issue 2: Pages Not Indexing
**Solution:**
- Wait 7 days (Google needs time)
- Check robots.txt isn't blocking pages
- Request indexing manually via URL Inspection

### Issue 3: Coverage Errors
**Solution:**
- Check specific error in Google Search Console
- Fix the issue (usually meta tags or redirects)
- Request re-indexing

### Issue 4: Duplicate Content
**Solution:**
- Ensure canonical URLs are correct (already done ✅)
- Check for www vs non-www issues
- Verify no duplicate pages exist
