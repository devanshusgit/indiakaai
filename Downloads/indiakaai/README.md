# IndiaKaAI - India's #1 AI Tools Directory

Discover 200+ hand-picked AI tools for writing, coding, design, video, and more.

## 🚀 Live Site
**https://indiakaai.com**

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript
- Tailwind CSS (Clay Design System)
- Firebase Authentication (Google Sign-In)
- Supabase (Database)
- EmailJS (Contact Forms)
- Google AdSense (Monetization)
- Vercel (Hosting)

## 📁 Project Structure
```
indiakaai/
├── index.html          # Main HTML file
├── css/
│   ├── style.css       # (unused - migrated to Tailwind)
│   └── custom.css      # Custom CSS & Clay design
├── js/
│   ├── firebase.js     # Firebase config
│   ├── auth.js         # Authentication logic
│   ├── api.js          # EmailJS & Supabase config
│   └── app.js          # Main app logic
├── favicon.svg         # Site favicon
└── DESIGN.md           # Clay design system guide
```
